## Phase 2: The "Secret Sauce" Servo Engine (Step-by-Step Compilation)
*Yes, this can be done locally on your PC via VS Code in interrupted steps. Cargo (Rust's build system) caches progress. If we stop the build or if it crashes, it resumes exactly where it left off!*

- [ ] **Step 2A: Verify Prerequisites:**
    - Check if Python, CMake, Git, and Visual Studio C++ Build Tools (with LLVM/Clang) are installed on your Windows machine (Required to compile Servo's C++ WebRender components).
- [ ] **Step 2B: Initial Fetch & Dependency Build:**
    - Run `cargo build --features servo_real`. Cargo will download the giant Servo repository.
    - Allow it to compile the pure-Rust dependencies (this caches automatically).
- [ ] **Step 2C: Core Servo Compilation (The Heavy Lift):**
    - Continue the `cargo build`. This is the part that takes 1-2 hours. You can press `Ctrl+C` to pause the terminal at any time, and next time we run it, it picks up right where it paused.
- [ ] **Step 2D: UI Integration & Testing:**
    - Once compilation succeeds, hook the live WebRender pixel feed into your GTK/egui window instead of the static `.png` fallback.

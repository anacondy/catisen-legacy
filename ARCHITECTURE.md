# Catisen Legacy

This repository is the historical egui/eframe + reqwest/rustls privacy HTTP client extracted from commit `ea726eb`.

Supported scope: static HTML fetching, source view, reader/text view, diagnostics, and explicitly configured Tor-aware HTTP requests.

This is not a full JavaScript/CSS browser. It must not claim live DOM, BOM, WebKitGTK, WebView2, or Chrome-compatible rendering.
